## 功能与下载速查

烽火 CPE Android 管理工具：设备登录与状态读取、网页管理入口、手机蜂窝信号查看；源码工程，需连接对应设备。

### 下载到另一台电脑

- [下载源码 ZIP](https://github.com/lucc1832/CPEMIn/archive/refs/heads/master.zip)，或在仓库页面选择 **Code → Download ZIP**。
- 使用 GitHub CLI：`gh repo clone lucc1832/CPEMIn`。
- 整理时未发现本仓库 Releases 的安装包附件；上述 ZIP 是源码/资料，不是现成安装包。原说明中的其他下载入口见下文。

### 使用与迁移

使用 Android Studio 构建 Android 应用；设备状态功能需要连接可访问的 CPE 网络并填写设备登录信息，手机信号读取需要相关权限。

说明依据本仓库文档与源码整理于 2026-09-23；此次整理未运行应用或活动脚本。
